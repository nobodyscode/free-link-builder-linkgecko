# Evidence rules

A link plan is only useful if the person acting on it can trust each line. These rules apply to every finding and every draft.

1. **Report what you observed.** Each finding needs a source: a page you read, a search result, a file you fetched, or text the user pasted.
2. **Label inference.** Mark anything you worked out rather than saw as "inferred". Mark anything you could not check as "not checked".
3. **Invent nothing.** No metrics, quotes, customers, results, contact details or first-hand experience. If a draft needs a fact you lack, leave a bracketed placeholder such as `[your real number]`.
4. **Keep the sample honest.** "Absent from the 12 pages I read" is a finding. "Absent from the web" is not.
5. **Date every report.** Search results and pages change. Put the collection date at the top.
6. **Keep search results and AI citations apart.** A web search result shows what ranks. It does not prove an AI assistant cites that page. Call a page "AI-cited" only when you can see the citation, or the user pasted an answer that shows it.
7. **Leave authority metrics blank without data.** Do not estimate Domain Rating, Domain Authority, traffic or backlink counts. Use them only when the user provides an export or a connected tool returns them.
8. **Ask before anything public.** Never send, post, vote, message or sign up on the user's behalf. You prepare the work and the user decides what goes out.
