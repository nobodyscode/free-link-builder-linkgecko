# Link quality check

Tell the user whether a link is worth pursuing before they spend money or time on it.

Read `references/evidence-rules.md` before you begin. If LinkGecko tools are connected, follow `references/linkgecko-connector.md`.

## 1. Get the inputs

Accept any of these: one URL, a list of up to 25 domains, a vendor's sheet, or a pasted offer email. Ask for the user's own site as well, because audience fit decides much of the verdict.

If the user has metrics from Ahrefs, Semrush, Moz or Similarweb, use them. Without them, leave those fields blank and say so. Do not estimate.

## 2. Inspect each site

Read the homepage, the blog index, two recent posts, and any "write for us", "advertise" or "sponsored" page. Then go through `references/red-flags.md` and record what you saw, with the URL.

For a list longer than 10 domains, check the homepage and one recent post first. Read further only where the verdict is unclear, and state the depth you used.

## 3. Read the offer

When the link comes from an offer, check for:

- A promised "dofollow" link for a fee, with no label on the post
- Prices set by Domain Rating or Domain Authority
- Guaranteed rankings or guaranteed placement on any topic
- No named site until you pay
- A claim that the link is "permanent" or "safe from Google"

Google's spam policies name buying links that pass ranking credit, expired domain abuse and site reputation abuse. Say this plainly when it applies. A labelled sponsorship can still make sense when the site's readers are the buyer.

## 4. Give a verdict

Use one of three verdicts for each site:

- **Pursue:** a real audience that matches the buyer, an editorial standard you can see, and no serious flags.
- **Caution:** mixed signals. Name what would settle it, such as seeing traffic data or asking for an editorial example.
- **Skip:** several serious flags, or an audience that has nothing to do with the buyer.

Base the verdict on what you saw. Keep "this site looks poor" apart from "Google will penalize this", because you cannot know the second.

## 5. Deliver

Give a table with the site, verdict, audience fit, flags seen and the evidence URL. Under it, explain only the verdicts that may surprise the user. For a vendor list, finish with the count of each verdict and what share of the list you would keep.

Save a report only when the user asks or the list has more than 10 sites.
